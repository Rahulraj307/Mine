## 🎯 Project Levels

### Beginner Projects (Weeks 1-4)
Focus: HTML/CSS, JavaScript basics, simple Angular

| Project | Skills Practiced |
|---------|-----------------|
| Portfolio Website | HTML, CSS, Flexbox/Grid |
| Todo App | Angular components, services |
| Calculator | JavaScript logic |
| Weather Widget | HTTP calls, async |

### Intermediate Projects (Weeks 5-8)
Focus: Full MEAN stack integration

| Project | Skills Practiced |
|---------|-----------------|
| Blog Platform | CRUD, authentication |
| E-commerce Store | Cart, payments, state |
| Task Manager | Real-time, WebSockets |
| Chat Application | Socket.IO, RxJS |

### Advanced Projects (Weeks 9-12)
Focus: Architecture, scale, deployment

| Project | Skills Practiced |
|---------|-----------------|
| Social Network | Microservices, feeds |
| Analytics Dashboard | Data viz, aggregation |
| SaaS Platform | Multi-tenancy, billing |
