## 📖 Learning Paths

### 🟢 Beginner Path (4-6 weeks)
1. HTML → CSS → JavaScript basics
2. Git fundamentals
3. Node.js introduction
4. MongoDB basics

### 🟡 Intermediate Path (6-8 weeks)
1. Advanced JavaScript (async, closures)
2. TypeScript
3. Angular fundamentals
4. Express REST APIs
5. MongoDB aggregation

### 🔴 Advanced Path (8+ weeks)
1. Angular advanced (Signals, standalone)
2. Full MEAN project
3. Docker deployment
4. System design basics
5. Interview preparation
