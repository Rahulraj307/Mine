# 13 Resources: The Treasure Trove

> **Goal**: A curated list of the absolute best learning material on the web. No fluff.

---

## 🌟 Official Documentation (The Bible)
Always read these first. Blogs get outdated. Docs are forever.

*   [MDN Web Docs](https://developer.mozilla.org/en-US/) - HTML, CSS, JS Standard.
*   [Angular Docs](https://angular.io/) - The definitive guide.
*   [Node.js Docs](https://nodejs.org/en/docs/) - API reference.
*   [RxJS API](https://rxjs.dev/) - Operator marbles and examples.
*   [MongoDB Manual](https://www.mongodb.com/docs/manual/) - Server capability.

---

## 📚 Essential Reading (Deep Dives)

### JavaScript
*   [JavaScript.info](https://javascript.info/) - The modern tutorial. Goes deeper than MDN.
*   [You Don't Know JS (Github)](https://github.com/getify/You-Dont-Know-JS) - Kyle Simpson's legendary series on closures, this, prototypes.
*   [Patterns.dev](https://patterns.dev/) - Modern web app design patterns.

### Angular
*   [Angular University](https://blog.angular-university.io/) - High-quality deep dives by Vasco Cavalheiro.
*   [NetBasal](https://netbasal.com/) - Advanced Angular engineering techniques.
*   [Total TypeScript](https://www.totaltypescript.com/) - Matt Pocock's TS wizardry.

### Backend & System Design
*   [System Design Primer](https://github.com/donnemartin/system-design-primer) - How to scale from 1 to 1M users.
*   [Node.js Best Practices](https://github.com/goldbergyoni/nodebestpractices) - 80+ articles on architecture/security.
*   [12 Factor App](https://12factor.net/) - Methodology for building SaaS apps.

## 🛠️ Tools of the Trade

*   [CanIUse.com](https://caniuse.com/) - Browser support tables.
*   [BundlePhobia](https://bundlephobia.com/) - Check npm package cost.
*   [RxMarbles](https://rxmarbles.com/) - Interactive diagrams of Observables.
*   [AST Explorer](https://astexplorer.net/) - See how code is parsed (great for writing ESLint rules).
