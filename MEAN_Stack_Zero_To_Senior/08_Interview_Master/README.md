## 🎯 The Three Levels

| Level | Focus | Interview Style |
|-------|-------|-----------------|
| **Fresher** | Fundamentals | "What is X?" |
| **Mid** | Implementation | "How does X work?" |
| **Senior** | Architecture | "When NOT to use X?" |

## 📋 Mastery Checklist

### Fresher Goals
- [ ] Explain core JS concepts clearly
- [ ] Write basic Angular components
- [ ] Understand HTTP and REST
- [ ] Know MongoDB CRUD

### Mid-Level Goals
- [ ] Explain WHY concepts work
- [ ] Design features end-to-end
- [ ] Debug complex issues
- [ ] Optimize for performance

### Senior Goals
- [ ] Architect entire systems
- [ ] Evaluate trade-offs
- [ ] Mentor and lead
- [ ] Handle scale concerns
